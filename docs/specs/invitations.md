## 7-6. 招待

グループのメンバーが招待リンクを発行し、リンクを開いた人がそのグループに参加する。二人（以上）で同じ行きたい場所を共有するための機能（[11章](overview.md#11-実装の順序)の段階4）。

> 実装は2つの PR に分けている（#59）。リンクの発行と、リンクを開いたときの表示までを先に作り、「参加する」ボタンと参加処理（下の「参加する」「参加できない人」）はあとの PR で作る。

**入口**

- ナビバーのユーザー名のドロップダウンにある「メンバーを招待」から発行画面を開く（[ナビバー](overview.md#ナビバー)）

**リンクの発行**

- 発行画面には、リンクは1回使うと使えなくなること、使われなくても発行から72時間で使えなくなることを説明し、「招待リンクを発行する」ボタンを置く。画面を開いただけではリンクを発行しない
- 発行すると、リンクの画面に移る。リンクは読み取り専用の入力欄に出し、「コピー」ボタンでクリップボードにコピーできる（コピーすると「コピーしました」に変わる）。有効期限（日本時間）も表示する
- リンクの URL には推測できないランダムな文字列（トークン）を使う
- グループの人数に上限は設けない。3人目以降を招待するときは新しいリンクを発行する
- 発行済みリンクの一覧表示・取り消しはしない

**リンクを開いたとき**

未ログインで開いた場合はログイン画面へ移る。ログイン／サインアップ後は自動でリンクの画面に戻る。

ログイン中に開いた場合は、次のどれかを表示する。

1. 使えないリンク — トークンが存在しない・使用済み・期限切れ（発行から72時間）のどれでも「このリンクは使えません」と表示する（404）。どの理由で使えないかは区別しない
2. すでにそのグループのメンバー — 「すでにこのグループに参加しています」と表示し、行きたい場所へのリンクを置く。リンクは使用済みにしない
3. それ以外 — 「◯◯さんのグループに参加しますか？今のグループの場所（N件）は参加先へ移ります」と表示する（◯◯はリンクを発行した人の名前、N は消化済みも含む今のグループの場所の件数）。開いただけでは参加しない

**参加する**

- 確認画面の「参加する」ボタンを押したときに参加する
- 参加すると、元のグループの場所（訪問記録を含む）を参加先のグループへ移してから、元のグループを削除する（[9章](overview.md#9-まだ決まっていないこと)の「招待承諾時の元グループの扱い」は案2に決定）
- 使ったリンクは使用済みになり、以降は使えない

**参加できない人**

- 自分以外のメンバーがいるグループに所属している人は参加できない（元のグループを削除すると、ほかのメンバーが巻き込まれるため）

**権限**

- 発行したリンクの画面は、そのグループのメンバーだけが見られる。他のグループの招待の id を直接指定した場合は見つからない扱い（404）にする（「[10. 技術方針](overview.md#10-技術方針)」の認可エラーの方針を参照）
- リンクを開く画面は、リンクを知っていればどのグループの人でも開ける

**やらないこと**

- メールでの招待、招待コード
- グループからの退出、メンバーの削除
- 複数グループへの所属・切り替え（1人1グループのまま）
