# 仕様書

このディレクトリにリポジトリの仕様書を置く。

## ファイル構成

| ファイル | 書くこと |
|---|---|
| [overview.md](overview.md) | 全体に関わる内容。前書き、これは何か、解く課題、競合と差別化、やらないこと、用語、データモデル、ナビバー、まだ決まっていないこと、技術方針、実装の順序、判断の背景 |
| [places.md](places.md) | 行きたい場所の登録・一覧・編集・削除（7-1 / 7-2 / 7-5） |
| [decisions.md](decisions.md) | 今日決める画面と提案ロジック（7-3 / 8） |
| [visits.md](visits.md) | 訪問記録（7-4） |

## 分け方

- 全体に関わる内容は `overview.md` に書く
- 機能ごとの内容は、その機能のファイルに書く
- 実装計画時（`/start-issue` のプランモード）やレビュー時にエージェントが参照する前提のドキュメントなので、実装との乖離が出たら都度更新する
