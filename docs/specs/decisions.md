## 7-3. 今日決める（製品の核）

開いた時点で**すでに3件表示されている**。ユーザーに条件を入力させない。

- 距離感の絞り込みは「近場 / 日帰り / 遠出」の3ボタン。デフォルトは全件
- 各カードに表示するのは、場所の名前 / 一言 / 距離感 / 登録からの経過期間
- 場所の名前を大きく目立たせ、一言はその下に通常の大きさで置く
- 行きたい度は**合計のみ**を表示する（暫定。[9節](overview.md#9-まだ決まっていないこと)参照）
- 候補が3件未満なら、ある分だけ表示する
- 山札（[8章](#8-提案ロジック)）は1日1つで、距離感を切り替えても共通。日本時間で日付が変わったらリセットする
- 山札が減るのは `別の3件` を押したときだけ。押した時点で表示中の3件を見送り、次の3件を引く
- 再読み込みでは同じ3件を表示し、山札は減らさない
- 手札（表示中の3件）は距離感ごとに覚える。距離感を切り替えても山札は減らず、元の距離感に戻ると同じ3件を表示する
- 他の距離感で見送った場所は手札から外し、補充はしない。手札が0件になったら新しく3件を引く
- 引き切ったあとに新しく登録した場所は、再読み込みで表示する

**アクション**

- `別の3件` — 表示中の3件を見送り、まだ見送っていない場所から次の3件を引く。回数制限なし
- `これにする` — Google マップの検索 URL を開く

**候補が尽きたとき**

場所が0件になる理由（登録なし・すべて消化・今日の候補を引き切った・選んだ距離感に場所がない）によらず、一律で「場所がありません」と表示する。登録画面への導線をここに置く。

## 8. 提案ロジック

### 3件の内訳

| 枠 | 選び方 |
|---|---|
| 2件 | 行きたい度の合計が上位層の中からランダム |
| 1件 | **スコアは高いのに古いもの**（塩漬け）からランダム |

> 段階2（[11章](overview.md#11-実装の順序)）では行きたい度がまだないため、暫定で全件からランダムに3件を選ぶ。行きたい度を使う選び方（上位層・塩漬け枠）は段階4で入れる。

塩漬け枠を「最も古いもの」にしないこと。古いまま残っているのはスコアが低いからである場合が多く、そのまま出すと「二人とも行きたくない場所」が毎日1枠を占領してノイズになる。

該当が0件の場合は、その枠も上位層から埋める。

### 山札

- その日「別の3件」で見送った `place_id` を保持し、同じ日には再提示しない
- 状態はセッションで保持する。DB に保存する必要はない
- 日付が変わったらリセットする

### 除外

- 消化済み（`want_again` が false の visits がある）place は候補に含めない
- 「また行きたい」（`want_again` が true の visits しかない）place は候補に含める
