## 7-4. 訪問記録

行った場所に、訪問日と「また行きたいか」を記録する。「また行きたいか」が行きたい場所から外す分かれ目になる。

**入口**

- 一覧（[7-2](places.md#7-2-一覧)）の各行の「訪問を記録」リンクから記録画面を開く。今日決める画面（[7-3](decisions.md#7-3-今日決める製品の核)）からは誘導しない
- 記録画面には対象の場所の名前と、行きたい場所に戻るリンクを置く

**入力項目**

1. 訪問日 — 初期値は今日（日本時間）。明日以降の日付はエラーにする
2. また行きたいか — 「はい / いいえ」から選ぶ。初期値なし。必須

入力エラーのときは、入力値（選んだ「はい / いいえ」を含む）を残したまま記録画面を再表示する。

**はい / いいえの違い**

- いいえ：消化済みになり、行きたい場所と今日決めるから外れる。「○○を訪問済みにしました」と表示して行きたい場所に戻る
- はい：行きたい場所に残り、今日決めるにも出る。次に行ったらまた記録できる（1つの場所に何件でも記録できる）。「○○の訪問を記録しました（行きたい場所に残ります）」と表示して行きたい場所に戻る

**訪問記録の一覧**

画面名は「訪問記録」（ナビバーの「訪問記録」から開く）。

- 自分のグループの訪問記録を**訪問日の新しい順**に並べる（同じ訪問日なら、あとに記録したものが上）
- 各行に表示するのは、場所の名前 / 一言 / 距離感 / 訪問日 / また行きたいか（はい / いいえ）
- 0件のときは「まだ訪問した場所はありません」と表示する

**取り消し**

- 訪問記録の一覧の各行に「取り消す」ボタンを置く。押すと確認ダイアログを出し、OK で訪問記録を消す
- 取り消したら「○○の訪問記録を取り消しました」と表示して訪問記録の一覧に戻る
- 「いいえ」の記録を取り消すと、その場所は行きたい場所に戻る（ほかに「いいえ」の記録がなければ）

**権限**

自分のグループの場所にだけ記録・取り消しができる。他のグループの場所の id を直接指定した場合、記録画面の表示・記録はできず、見つからない扱い（404）にする。他のグループの記録の id を直接指定した場合も、取り消しはできず、見つからない扱いにする（「[10. 技術方針](overview.md#10-技術方針)」の認可エラーの方針を参照）。消化済みの場所の記録画面・記録も、自分のグループかどうかによらず見つからない扱いにする。
